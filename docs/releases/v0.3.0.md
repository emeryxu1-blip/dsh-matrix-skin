# Matrix Skin 0.3.0

The Matrix look, built for everyday coding.

Unofficial community plugin for DeepSeek Harness Desktop and Web, independently developed and maintained. MIT licensed.

![Matrix Skin conversation](https://github.com/emeryxu1-blip/dsh-matrix-skin/releases/download/v0.3.0/matrix-chat.png)

## What changed

- Quiet green accents, solid dark surfaces, and clear text tiers.
- Native fonts, font-size preferences, layouts, controls, and reasoning disclosures remain intact.
- Native syntax highlighting, diffs, warnings, errors, and terminal colors remain intact.
- Decorative rain appears only behind the empty-session welcome area. It stops during active work and when menus, dialogs, or sidebars open.
- Reduced motion, forced colors, light appearance, compact windows, and background pages suppress decorative animation.
- No plugin telemetry, credential access, session-content upload, or model-request interception.

## Install in Desktop

1. Open DeepSeek Harness normally.
2. Select **Plugins → Add plugin** and paste `github:emeryxu1-blip/dsh-matrix-skin#v0.3.0`.
3. Install and enable the bundle; restart if requested.

For future GitHub revisions, add the source again through Plugins. Desktop and Web have separate plugin installations. The release also includes a prebuilt `dsh-matrix-skin.tgz` and SHA-256 checksum.

## Compatibility and verification

- Live Desktop inspection: official DSH Desktop `0.2.2-rc.3` on macOS.
- Public screenshots and video: actual DSH `0.2.2-rc.3` Web UI on macOS, in an isolated demo profile containing fictional content. The 25-second video is a labeled still-capture walkthrough.
- Build and syntax checks pass; all **41 automated tests** pass.
- Earlier Web contracts remain supported in the peer dependency range; this release does not claim new live testing on every historical version or OS.
- Focused contrast and interface checks do not constitute a full accessibility certification.
